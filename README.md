# MOSEI-ARE

**CMU-MOSEI多模态情感建模项目**。名称对应题目的三项主线：时序对齐（Alignment）、缺失鲁棒性（Robustness）和可解释性（Explainability）。

| 目录 | 用途 | 状态 |
|---|---|---|
| `problem1/` | 附件1特征提取、时序对齐和全量核验 | 已完成可复现流程与100条结果 |
| `problem2/` | 附件2训练划分、附件3鲁棒预测 | 已预建，待实现 |
| `problem3/` | 附件2训练划分、附件4可解释预测 | 已预建，待实现 |
| `models/` | 问题二、三共用的主模型定义及版本 | 主模型实现前先在此定接口 |
| `configs/` | 共用实验设置 | 已预建 |
| `data/` | 数据位置与版本约定 | 已建说明 |
| `docs/` | 方法决策和报告 | 已预建 |
| `legacy/` | 旧 SlotEmo 探索实验源码、文字结果与本地权重 | 已归档，不作为正式提交结果 |

每一问的专属代码、配置、验证及结果归入自己的目录。跨题复用的主模型只在 `models/` 保留一份。问题二和问题三分别记录自己的训练配置、所选权重与专项推理结果。

原始附件保留在库外 `../E题数据/E题数据/`，详情见 `data/README.md`。不要把原始视频、完整训练特征或预训练权重提交到Git。

题目原文Word保留在库外 `../复杂场景下多模态情感识别的数学建模与算法设计.docx`。
