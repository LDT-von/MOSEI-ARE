# SlotEmo 历史探索实验

`src/` 是原 SlotEmo 模型，`scripts/` 是三次训练及调试脚本，`experiments/` 是当时写出的文字结果。`outputs/` 留存三个本地最佳权重，已被 Git 忽略；新克隆的仓库不含权重。原目录迁入本仓库后，脚本中的机器绝对路径已改为当前目录和 `MOSEI_DATA_ROOT` 环境变量；模型结构及训练计算未改，也没有因迁移而重新训练。

默认按仓库旁边的 `E题数据/E题数据` 查找赛题附件。在其他机器上，先设置 `MOSEI_DATA_ROOT` 为包含“附件2-数据集特征文件”的目录。历史脚本从附件2的 `aligned_50.pkl` 读取已处理的文本、语音和视觉特征，输出权重至本目录 `outputs/`、文字结果至 `experiments/`。入口为 `scripts/exp1_baseline.py`、`scripts/exp2_v2.py`、`scripts/exp3_problem1.py`。

| 历史实验 | 验证集最佳 F1 | 旧测试集 F1 | 性质 |
|---|---:|---:|---|
| v1 baseline | 0.6184 | 0.6363 | 探索性基线 |
| v2 sparse | 0.4270 | 0.4659 | 探索性消融 |
| exp3 | 0.5196 | 0.5660 | 附件2特征上的探索 |

以上来自 `experiments/*_results.txt`，当前未独立复跑，也没有完整逐轮日志。先前口头总结的 v2 F1=0.6474 与现存结果不一致，不应引用为已核实成绩。`exp3_problem1.py` 的旧文件名容易误解：它没有从附件1原视频生成特征、逐词时间戳或视频帧对应，因此**不能用于证明正式问题一已完成**。正式问题一见仓库 `problem1/`。这些结果也不能代替问题二、三的正式训练和专项测试。

迁入前生成的 `experiments/exp3_problem1_alignment.json` 不是完整 JSON，保留在本地但不纳入 Git。历史结果和权重不随问题一提交包提交。
