# 问题三 可解释情感预测：预测证据的生成与溯源

## 1 问题定义

问题三在问题二训练的模型基础上，要求对每条预测给出**可溯源的情感证据**。具体要求：

- 对附件 2 验证/测试集：报告模型在有标签样本上的预测质量（Accuracy/F1/MAE/Pearson）
- 对每条预测：提供模态贡献度、局部证据窗口及到原文、音轨、视频帧的时间映射
- 对附件 4（无标签 20 条）：仅提交预测与证据，不做 F1/MAE 报告
- 所有证据必须可回查原始视频帧，不得以注意力权重冒充因果归因

## 2 方法

### 2.1 模型复用

使用问题二 Arm C 的最佳 checkpoint（`arm_C_seed_42/best.pt`，19.92 MB），不再重新训练。理由：相同的 `aligned_50` 输入接口保证特征对齐结构兼容，无需对附件 4 重新适配。

### 2.2 三层证据体系

#### 第一层：完整前向预测

```
clean_logits, clean_intensity = model.forward(sample)
clean_pred = argmax(clean_logits)
```

同时读取模型内部 `modality_weights`（归一化 softmax 权重），仅作**辅助展示**，不作为贡献证明。

#### 第二层：模态级反事实遮挡

对每种模态 m ∈ {text, audio, vision}：

1. 在**原本有效的位置**（`observed[m] & support`）上将该模态的输入置零
2. 同时将 `observed[m]` 在这些位置上设为 False（使模型知道该模态不可用）
3. 重新前向，得到 `ablated_logits[m], ablated_intensity[m]`
4. 计算极性 delta：`Δ_polarity[m] = clean_logits[clean_pred] - ablated_logits[m][clean_pred]`
5. 计算强度 delta：`Δ_intensity[m] = clean_intensity - ablated_intensity[m]`
6. 归一化：`norm[m] = |Δ_polarity[m]| / Σ_m |Δ_polarity[m]|`，保证模态间可比
7. `dominant_modality = argmax_m norm[m]`

归一化保证了模态间的比较不受 logits 尺度影响；所有操作在 GPU 上以批量方式高效执行。

#### 第三层：连续窗口局部证据扫描

对每种模态 m，滑动固定长度窗口（默认 6 位置 = 1.2 秒）：

1. 遍历所有 start ∈ [0, 50 - window_length]
2. 若窗口内无有效观测位置则跳过
3. 在窗口内遮挡该模态，重新前向
4. 记录 `logit_drop = clean_logits[target_class] - ablated_logits[target_class]`
5. 按 logit_drop 从大到小排序，取 top-k（默认 k=3）

文本模态额外排除 `[CLS]`（位置 0）和 `[SEP]`（最后有效位置），确保窗口落在实际内容词上。

### 2.3 时间映射

对齐版 50 位置对应 0.2 秒/格，窗口起止位置映射为：
- `start_seconds = (start + 0.5) × 0.2`
- `end_seconds = (end + 0.5) × 0.2`

这是均匀网格映射，用于在原始 MP4 中快速跳帧，不是精确的词边界或帧号。

### 2.4 证据的语义约束

**预测依赖 ≠ 因果归因**。Delta 回答的问题是"如果我在推理时遮掉这个模态/窗口，预测会怎样变化？"，而不是"这个模态/时段是否是情绪产生的真实原因"。任何提交材料中必须明确区分二者。

## 5 输出格式

### 5.1 附件 4 CSV（20 行）

每行字段：

```
sample_id, polarity, intensity,
dominant_modality,
top_text_window, top_audio_window, top_vision_window,
text_polarity_delta, audio_polarity_delta, vision_polarity_delta,
intensity_delta_text, intensity_delta_audio, intensity_delta_vision,
raw_text_snippet, video_filename
```

- `top_*_window`：格式 `X.XX-Y.YYs (drop ±W.WWW)`
- `raw_text_snippet`：原文前 160 字符
- `video_filename`：对应 MP4 文件名（位于附件 4 对齐版 videos/ 目录）

## 6 局限性与改进方向

1. **证据质量**：6 位置（1.2 秒）窗口可能过于粗糙；可尝试 3 位置（0.6 秒）和 12 位置（2.4 秒）做敏感性分析。
2. **归一化基准**：当前用训练集先验（极性分布）作为 Shapley 空集基准，可改进为在验证集上对每个非空模态组合建立可靠性表。
3. **视频帧精定位**：当前仅报告网格秒数；结合问题一的词级强制对齐结果可以精化文本窗口的词边界。
4. **证据忠实性对照**：尚未实现"等长度随机窗口"作为对照来验证证据的显著性。
