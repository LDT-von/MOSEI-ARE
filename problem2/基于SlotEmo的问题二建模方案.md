# 问题二：在 SlotEmo 上建模局部连续缺失

状态：**共享模型、数据入口和训练/验证/推理代码已实现；正式实验和可提交的专项预测尚未完成**。本方案只使用赛题附件 2 的训练集拟合参数、验证集选方案；附件 3 的 30 条无标签样本只用于冻结后的推理和格式核验。运行由用户启动。

## 结论

可以沿用 SlotEmo 的“三模态投影 → Slot Attention → 融合 → 极性/强度双头”骨架。针对问题二只增加一个核心机制：**同位跨模态缺口补偿**。在对齐的 50 个位置上，某模态的一段特征缺失时，用同一位置仍可观察到的其他模态形成候选表示，并让一个小门控决定补偿强度。它针对的是连续局部缺失；不采用整模态重建、复杂扩散或更强的 Top-K 稀疏化。

在这个机制之外，还有四项必须修正的基础问题。它们是可运行、可比较的前提，不应被包装成额外创新：

| 现有代码位置 | 当前行为 | 问题二所需行为 |
| --- | --- | --- |
| `legacy/SlotEmo_experiments/scripts/exp1_baseline.py` | 读预计算 `text`，附件 3 对齐版没有这一字段 | 训练、验证、专项推理统一从 `text_bert` 词元输入；可在附件 2 **训练集**用 `text` 辅助蒸馏小型词元编码器，但验证也须走词元入口 |
| `src/slot_modules.py::MultiHeadSlotAttention` | 将掩码为 0 的位置替换为该样本模态均值，仍参加注意力更新 | 显式排除填充与缺失位置；无有效位置时跳过该模态，不能由随机 slot 产生伪证据 |
| `src/slot_model.py` | 回归头 `Tanh()` 输出限于 [-1,1]；原任务强度范围是 [-3,3] | 输出 `3*tanh(z)`，或使用无界输出并在报表中固定裁剪规则；本方案选择前者 |
| `src/slot_modules.py::MoESlotDecoder` 及旧实验 | 默认只保留 16 个 slot 中的 4 个；`Slot Attention` 在评估时仍随机初始化 slot | 先使用全部 slot 的软权重汇聚，并让验证/推理确定性；Top-K 只作为消融，不设为正式默认 |

旧脚本的“缺失增强”仅随机选择约 10% 的 batch 样本，且只在语音或视觉的一段设 mask；未训练文本缺失、不同位置/长度或双模态缺失。旧 `exp1` 测试 F1=0.6363 只能称为历史参考：它用 `text` 入口、旧掩码和旧回归头，不能直接证明问题二的专项效果。

## 数据入口与掩码

选用 `aligned_50.pkl` 及附件 3 的**对齐版本**，整个训练—验证—专项推理不混用 `unaligned_50.pkl`。附件 2 有 train=3395、valid=728、test=727；输入分别为 50 个位置、文本词元三路整数信息、74 维语音和 35 维视觉。附件 3 的每个文件顶层为 `test`，仅有 `text_bert`、`audio`、`vision`，没有预计算 `text`。其中 `text_bert` 存为浮点数，须检查有限、非负、整数值和词元范围后转为整型，不能直接送入词元嵌入层。

分别保存 `padding[m,t]`、`observed[m,t]` 和 `artificial_gap[m,t]`。文本的注意力掩码确定填充，词元 ID 0 不等于可用词元；`[CLS]`/`[SEP]` 可参与编码但不参与人工缺口采样。语音/视觉可用位置以原始、**标准化之前**的非零行和文本有效区间共同估计，并把“真实零向量与缺失/填充无法绝对区分”记入审计日志。训练集有效位置拟合标准化统计；先保存原始可用标记，再做标准化和人工遮挡，绝不让填充值经标准化变成假信号。若附件 3 未给显式缺口标签，就记录按原始零行得到的推断掩码及其不确定性，不据此选择超参数。

小型词元编码器建议从 `text_bert` 的 token ID、attention mask 和 segment ID 产生 128 维逐位置表示，使用位置嵌入和轻量上下文层。BERT 全量权重不作为提交模型；词元嵌入加 SlotEmo 参数应按实际序列化大小检查是否落在赛题 50 MB 限额内。若训练集 `text` 蒸馏有效，应单独作消融；被蒸馏的 `text` 仅是附件 2 提供的特征，不引入其他情感数据。

## 唯一新增机制：同位跨模态缺口补偿

令 `e[m,t]` 为投影后的 128 维表示，`o[m,t]∈{0,1}` 表示该模态该位置是否真实可观察。对缺失模态 `m`，只用**同一对齐位置**的其他可观察模态形成候选：

`c[m,t] = Σ_{n≠m} α[n,t] W[n→m] e[n,t]`，其中 `α[n,t]` 仅在 `o[n,t]=1` 的模态上归一化。

输出 `z[m,t] = o[m,t] e[m,t] + (1-o[m,t]) g[m,t] c[m,t]`。门控 `g[m,t]∈[0,1]` 只看可观察模态的表示、缺口指示、归一化位置和缺口边界距离；不看被遮掉的原值。如果该位置其余模态也都不可观察，则 `g=0`，该位置从该分支的 Slot Attention 中排除。将原始观察标志作为额外嵌入，避免补偿值被误认为实测信号。模态完好时 `z=e`，机制不改写原观测特征。

随后沿用三个模态的 Slot Attention 和双任务预测头。Slot Attention 采用真实有效位置掩码，并在输入上加入位置编码，使开头、中间、末尾缺口可区分；分类侧对全部 slot 软汇聚，模态全缺失时其融合权重为 0。回归侧也按有效模态融合。推理时 slot 初始化固定为学习到的均值，保证同一输入重复推理一致。原有 `ReconstructionHead` 是整模态级开关，不能直接解决逐位置连续缺口；先不用，只有对照证实有效时才加逐位置辅助重建，并且只在人工遮掉、原本有效的位置算损失。

这是一条**待验证假设**：同位补偿应该比单纯丢弃缺口更好地保持局部情感线索，但当其他模态也失真或本来不一致时可能反而有害，所以门控、缺失标志和消融是必要的。

## 训练与检验协议

1. 训练集上生成连续块，随机覆盖文本、语音、视觉，含单模态和双模态、开头/中间/末尾、短/中/长缺口；只遮原本有效位置，并保留一定比例完整样本。缺口配置、种子和样本 ID 记录到配置/日志。缺失特征值置零，并传独立掩码。
2. 用三分类交叉熵加连续强度 Huber 损失共同训练；回归标签及预测保持 [-3,3] 原尺度。音频和视觉的标准化统计只由训练集有效位置估计。验证集固定一张缺口清单，不随 epoch 改动。
3. 同一 `text_bert` 入口、相同划分与验证缺口下做阶梯消融：A 小型文本编码器 + 修正后的 SlotEmo，完整输入训练；B=A+连续块增强；C=B+同位缺口补偿。另列“随机点丢失增强”和“Top-K slot”作为诊断对照；不把历史 `text` 入口的 F1 与 A/B/C 当严格同条件比较。
4. 预先固定验证集的缺失模态、位置、长度和随机种子。报告完整输入与各缺口组的 Accuracy、宏/加权 F1、MAE、Pearson、样本数及相对完整输入的下降；小组 Pearson 若标签或预测常数，应报告不可定义。对分类以宏 F1 为主，同时列出中性类召回。记录至少 3 个种子的均值和离散度；如果资源不够，先完成 1 个种子的流水线验证，再补齐正式实验。
5. 只用附件 2 `valid` 选择配置与 checkpoint；附件 2 `test` 做一次冻结后有标签检查，附件 3 的 30 条只产出逐样本极性、强度、输入质量标志和所用 checkpoint/config 哈希。附件 3 不可报告 F1/MAE，也不可据其输出回调阈值。

## 执行顺序与验收

先写共享模型到 `models/`，问题二的数据加载、掩码生成、训练/验证/专项推理放在 `problem2/`。首个验收点不是分数，而是同一输入重复推理一致、缺失值变化不影响被掩码结果、文本/语音/视觉各自缺口与全模态缺失均有限数值、训练/验证/专项输入字段一致、输出 30 行与附件 3 文件一一对应。再在用户的 Linux GPU 上跑 A/B/C 并比较验证曲线；只有 C 在相同缺口协议下稳定优于 B，才把同位补偿写成问题二的有效贡献。问题三可复用该主干，但它的解释忠实性验证另行完成。
