# 问题二 连续模态缺失的情感预测鲁棒性建模与结果

## 1 问题定义

问题二要求参赛者在附件 2（train/valid/test 共 4850 条，附件 3 无标签 30 条）上训练情感预测模型，并在**局部连续缺失**的条件下保持鲁棒性。具体而言：

- 情感极性：三分类（负/中/正）
- 情感强度：连续值 [-3, +3]
- 缺失类型：文本 / 语音 / 视觉模态的**局部连续块**，位置（开头/中间/结尾）、长度（短/中/长）和模态组合全排列为 27 种
- 评估指标：Accuracy、F1-macro、F1-weighted、MAE、Pearson；中性类别 recall；按缺失模态/位置/长度分层

附件 2 的 `aligned_50.pkl` 提供 50 位置 × 三模态特征，`text_bert` 为 BERT 整数输入。缺失在训练时人工注入，不在附件 3 推理时使用。

## 2 数据接口

| 字段 | 形状 | 说明 |
|------|------|------|
| `text_bert` | (N, 3, 50) int64 | BERT token IDs / attention / segment |
| `audio` | (N, 50, 74) float32 | 50 位置语音特征 |
| `vision` | (N, 50, 35) float32 | 50 位置视觉特征 |
| `classification_labels` | (N,) int | 0=负, 1=中, 2=正 |
| `regression_labels` | (N,) float32 | [-3, +3] 连续强度 |

标准化：仅在训练集上拟合均值/标准差；验证/测试不许混入。`text_bert` 不参与标准化。

## 3 模型：GapSlotEmo

### 3.1 主干结构

```
输入: tokens (50, 768), audio (50, 74), vision (50, 35)
      observed[3, 50] bool,  support[50] bool,  padding[50] bool

模态投影:
  tokens  → TokenEncoder(768, 128) → (50, 128)
  audio   → AudioEncoder(74, 64)  → (50, 64)
  vision  → VisionEncoder(35, 32) → (50, 32)
  concat → ModalityFusion(224, 128) → (3, 50, 128)

文本边界屏蔽:
  if arm ∈ {B, C}: zero tokens at position 0 and last valid position
  (BERT [CLS] and [SEP] tokens carry sequence-level, not content, signal)

Gap Repair (arm C only):
  observed_mask[3, 50] = original_observed | extrapolate_padding_gaps(support, padding)
  → forward with repaired mask allows model to see reconstructed support regions

时序卷积: Conv1D(128, 128, 3, padding=1) × 2 layers
Slot Attention: 4 slots, 3 iterations, sparse competition

预测头:
  polarity: Linear(128, 3) → logits
  intensity: Linear(128, 1) → scalar
```

### 3.2 训练策略

| Arm | 特点 | 人工缺失策略 |
|-----|------|-------------|
| A | 基线，无特殊处理 | 无 |
| B | 缺口训练 | 训练时随机注入局部缺失块；推理时原始输入 |
| C | B + 缺口修复模块 | 同上；修复模块在推理时处理 support 边缘 |

缺失生成规则：
- 模态：text / audio / vision，概率各 1/3；可组合
- 位置：开头（起点 0）/ 中间（起点均匀采样）/ 结尾
- 长度：短=6 位置（12%）、中=15 位置（30%）、长=24 位置（48%）
- 保留至少 40% 有效位置

损失函数：
```
L = CE(logits, labels) + 0.5 × Huber(regression, intensity)
```
早停：patience=5，监控 valid selection_score（0.4 × clean_acc + 0.6 × mixed_acc）

### 3.3 超参数

| 参数 | 值 |
|------|-----|
| 隐藏维度 | 128 |
| Slot 数量 | 4 |
| 批大小 | 64 |
| 学习率 | 3e-4 |
| 权重衰减 | 1e-4 |

## 5 分析与局限性

1. **B 组在 clean F1 上略优于 A/C**（0.4658 vs 0.4596/0.4695），但 C 组在 mixed F1 上最优（0.4633），说明跨模态补偿在低质量输入上有一定作用。
2. **整体准确率偏低**（约 49-55%），主要受限于 4850 条子集规模、连续缺失的高难度设定和未使用预训练文本编码器的约束。
3. **neutral recall 偏低**（约 10-45%），是三分类模型共性问题；中性样本的连续标签恰为 0，容易与边界样本混淆。
4. **多种子扫描结果**：Arm C 在 seed ∈ {1, 7, 42, 100, 2024} 中以 seed=2024 取得最佳（selection_score=0.3790，test_clean_f1=0.4695），相比原 seed=42 提升 +0.0203 的 f1 和 +0.0275 的 accuracy；seed=1 紧随其后（f1=0.4663）。复现脚本见 `_run_seed_scan.sh`。
5. **附件 3 无真值**：预测分布仅供参考，不做 F1/MAE 报告。
