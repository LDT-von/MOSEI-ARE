# 由用户启动的运行命令

代码检查已完成，助手不再自行启动训练。以下命令请按需要逐条执行。`smoke` 是短暂启动检查，会产生4次参数更新；`train` 才使用完整训练集。调试权重不可用于正式推理。

## Windows：当前这台有 GPU 的电脑

在 PowerShell 中进入仓库：

```powershell
cd 'C:\Users\栋栋\Desktop\E题\MOSEI-ARE'
```

需要重新做短暂 GPU 检查时：

```powershell
python -m problem2.scripts.run smoke --arm C --device cuda --output problem2/qa/user_gpu_check_01
```

决定正式训练时，分别执行三组；每组完成后再执行下一组：

```powershell
python -m problem2.scripts.run train --arm A --seed 42 --device cuda
python -m problem2.scripts.run train --arm B --seed 42 --device cuda
python -m problem2.scripts.run train --arm C --seed 42 --device cuda
```

A=完整输入基线；B=连续缺口训练；C=连续缺口训练+同位补偿。默认每组最多30个 epoch，根据固定验证条件早停；输出位于 `problem2/outputs/arm_A_seed_42` 等目录。已有目录若包含实验记录，程序拒绝覆盖；可用 `--output` 指定新目录。

## Linux：你的另一台电脑

在仓库根目录先安装依赖，再指定数据根目录。数据根须包含赛题原始名称的附件2、附件3文件夹。

```bash
python -m pip install -r problem2/requirements.txt
export MOSEI_DATA_ROOT='/实际路径/E题数据'
python -m problem2.scripts.run smoke --arm C --device cuda --output problem2/qa/linux_gpu_check_01
```

检查通过后，自行执行上面的 A/B/C `train` 命令，Linux 命令相同。当前只在本机 Windows 的 CPU/CUDA 上试跑过，Linux 驱动环境还需在你机器上确认。

## 验证与生成正式输出

先对 A/B/C 各自的最佳权重运行验证，只依照验证结果选模型。下面用 C 组路径示范，换为实际选中的组：

```text
python -m problem2.scripts.run evaluate --checkpoint problem2/outputs/arm_C_seed_42/best.pt --split valid --grid --device cuda
```

模型和设置冻结后，才运行一次有标签测试及附件3输出：

```text
python -m problem2.scripts.run evaluate --checkpoint problem2/outputs/arm_C_seed_42/best.pt --split test --device cuda
python -m problem2.scripts.run infer --checkpoint problem2/outputs/arm_C_seed_42/best.pt --device cuda
```

正式附件3 CSV 位于对应权重目录，含30条极性/强度预测。附件3没有标签，不能据此计算 F1 或 MAE。不要选用 `qa/` 中的调试或中止权重。
